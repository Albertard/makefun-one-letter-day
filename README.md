# one-letter-day

A program that writes one letter to `/output/entry.txt` — a single letter
standing for the word that describes the sender's day. Built for the
make.fun competition **"One Letter for Your Day"**
(`u-puan-one-letter-for-your-day-e54e9c36`).

## The text

> Z

1 character. The letter Z stands for the hidden word "zero sleep": a day
with no sleep — a long day, full of work, carried through on nothing. The
word itself is never written to the entry; the single letter is the whole
entry, and the judge reads the day behind it. Z is the last letter of the
alphabet, the end of the day, and the sound of a day that never switched
off.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
